## 🌟 在线体验 (Live Demo)

👉 **[点击访问 GitHub Pages 交互式展示画廊](https://holynova.github.io/elden-ring-liveaction/)**

页面内置遵循 **Emil Kowalski's Design Engineering & Prototyping Philosophy** 的三维交互原型切换器（底部悬浮胶囊），支持键盘 `1` / `2` / `3` 键、左右方向键或点击即时无感切换：
- **Variant 1: Editorial (典藏画册)** — 典雅大画幅展览体验，大幅图版、版画编号、摄影笔记与策展语录。
- **Variant 2: Filmstrip (35mm胶片)** — 电影暗房放映机体验，胶卷齿孔、EXP编号、横向无尽轮播与胶片快门感。
- **Variant 3: Archive (密室档案)** — 密集档案库，支持 NPCs / BOSSes / Landscapes 多分类筛选，并支持鼠标悬浮左右滑动的 **Before / After (原画 vs 真人实拍)** 对比滑块。

## 📷 视觉重构核心哲学 (Real-Human Craft)

针对传统 AI 生图中常见的“CG 虚浮模型、二次元磨皮假面、游戏引擎平滑质感”，本项目全面转向**真实光学相机摄影与电影级实物道具冷锻管线**：
1. **真实皮肤质感与呼吸感**：肉眼可见的细密毛孔、微小雀斑、自然唇纹、疲惫战痕与眼睑血色，保留风中凌乱吹拂的发丝。
2. **纯实物手打道具**：手工冷锻敲打带有微小凹坑与氧化暗痕的黄铜板甲、粗剪羊毛织物、真实亚麻布与皮革。
3. **真实环境光学快门**：深秋古森林中战马鼻孔喷出的真实白雾、泥泞古道飞溅泥浆、室内微弱烛光与清晨薄雾空气透视。
